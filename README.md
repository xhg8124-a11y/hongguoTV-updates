# 红果 TV · Android TV 原生客户端

红果短剧的 Android TV 原生应用（Kotlin 编写，无 Node/JS/React Native 运行时）。面向电视遥控器交互设计：原生焦点体系、5% 安全边距、五列海报网格、聚焦行完整滚入视口。

## 主要功能

- **内容浏览**：首页推荐（继续观看/热门发现/新剧发现）、排行榜（全部/真人剧/漫剧/AI剧/系列剧 × 推荐榜/热播榜/必看榜等子榜）、搜索（支持手机扫码输入）
- **账号登录**：登录红果账号，播放历史多端同步
- **播放**：保持画面比例、暂停、前后跳转、上下集、自动连播、断点续播；可选 720P / 1080P 上限；预加载下一集减少卡顿
- **详情**：剧集简介、分集列表（20 集分组）、同系列多季切换
- **个人数据**：本机收藏、稍后看、最近观看（最多 200 条）、预约（未上线剧上线提醒）；登录后云端同步观看历史与预约
- **自动更新**：前台浏览时定期检查新版，下载后校验 SHA-256 与签名，由系统安装确认

## 安装与更新

电视端通过本仓库 Release 的 `latest/download/update.json` 检查新版本，下载 APK 并校验 SHA-256 与签名后由系统安装确认。首次需手动安装 APK 并允许「安装未知来源应用」，之后更新无需传文件。

系统要求：Android 8.0（API 26）及以上，ARM64 设备。
